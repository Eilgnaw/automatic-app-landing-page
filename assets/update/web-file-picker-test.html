Umiibo File Picker Test

Test single-file, regular multi-file, and folder selection in order. The third test should display game categories in the Umiibo built-in browser and return all Amiibo data in the selected category at once.

1. Select a Single File

Expected: the regular file source picker appears and returns exactly one file.

No file selected

2. Select Multiple Files

Expected: the regular file source picker still appears and does not open game categories. One or more files may be selected at once.

No files selected

3. Select a Folder

Expected: Umiibo displays game categories. After selecting and confirming a category, the page receives all of its .bin files.

No folder selected

Umiibo should use the selected game category as the folder name, so each file’s webkitRelativePath should be “Game category/file-name.bin”.

Test Criteria
  • Single file: exactly one readable file must be returned.
  • Multiple files: the game category picker must not appear.
  • Folder: the game category picker should return every file in the selected category.
  • Each file displays its size, first 32 bytes, and SHA-256. Amiibo data is commonly 540 bytes.
