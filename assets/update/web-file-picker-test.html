Umiibo 文件选择测试

请依次测试单文件、普通多文件和文件夹。第三项在 Umiibo 内置浏览器中应显示游戏分类， 选择后一次返回该分类下的全部 Amiibo 数据。

1. 选择单个文件

预期：显示普通文件来源选择界面，最终只返回一个文件。

尚未选择文件

2. 选择普通多文件

预期：仍显示普通文件来源选择界面，不应误进入游戏分类。可一次选择一个或多个文件。

尚未选择文件

3. 选择文件夹

预期：Umiibo 显示游戏分类。选择并确认后，网页收到该分类下的全部 .bin 文件。

尚未选择文件夹

Umiibo 应把所选游戏分类作为目录名，因此每个文件的 webkitRelativePath 应为“游戏分类/文件名.bin”。

测试判断标准
  • 单文件：文件数量必须为 1，网页能读取文件内容。
  • 普通多文件：不能弹出游戏分类选择页。
  • 文件夹：应弹出游戏分类页，并返回所选分类的全部数据。
  • 每个文件会显示大小、前 32 字节和 SHA-256；常见 Amiibo 数据大小为 540 字节。
